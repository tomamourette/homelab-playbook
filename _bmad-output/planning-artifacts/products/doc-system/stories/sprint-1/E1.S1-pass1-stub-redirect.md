# Story E1.S1: Pass 1 — CLAUDE.md → @AGENTS.md stub redirect

## User Story

As the homelab operator, I want to rename the existing root `CLAUDE.md` to `AGENTS.md` and create a stub `CLAUDE.md` whose only content is `@AGENTS.md`, so that Claude Code, OpenAI Codex, Cursor, and Continue can all read the same canonical agent-instruction file without duplication, per the Anthropic-endorsed Astral pattern.

## Context

This is the FIRST story in the Codebase Documentation System MVP and the smallest possible step on the schema-migration critical path. It validates the cross-tool stub-redirect pattern in production (the homelab repo) before any audit cuts (E1.S2), topic splits (E1.S3), path-scoped rules (E1.S4), or settings.json fences (E1.S5) are attempted. Pass 1 is intentionally **independent of Pass 2**: this story changes only filename + a one-line stub, and adds zero new content. If the stub-redirect fails for any reason, this story is reversed by a single `git revert` and no later story is blocked. Performing it first lets every subsequent epic story assume the AGENTS.md filename as ground truth.

## Anthropic-Endorsed Pattern

Verbatim from https://docs.claude.com/en/docs/claude-code/memory:

> "Claude Code reads `CLAUDE.md`, not `AGENTS.md`. If your repository already uses `AGENTS.md` for other coding agents, create a `CLAUDE.md` that imports it so both tools read the same instructions without duplicating them. You can also add Claude-specific instructions below the import."

The stub `CLAUDE.md` containing only `@AGENTS.md` is the minimal expression of this pattern: zero Claude-specific content today, full pass-through to the canonical file.

## Acceptance Criteria (INVEST)

Each AC is independently verifiable in <5 min by an operator at a shell.

1. **AC1 — File rename succeeds.** After Step 1, `/home/developer/workspace/homelab/AGENTS.md` exists and `/home/developer/workspace/homelab/CLAUDE.md` does NOT (transient state, before Step 2). Verify: `ls /home/developer/workspace/homelab/AGENTS.md` exits 0; `ls /home/developer/workspace/homelab/CLAUDE.md` exits non-zero.

2. **AC2 — Stub CLAUDE.md exact content.** After Step 2, the stub file contains exactly the 11 bytes `@AGENTS.md\n` and nothing else (no frontmatter, no comments, no trailing whitespace beyond the single newline). Verify: `wc -c /home/developer/workspace/homelab/CLAUDE.md` reports `11`; `cat /home/developer/workspace/homelab/CLAUDE.md` shows `@AGENTS.md` with one trailing newline.

3. **AC3 — AGENTS.md is byte-identical to prior CLAUDE.md.** The new `AGENTS.md` has the same SHA-256 as the pre-Step-1 `CLAUDE.md` (size 6515 bytes per pre-flight). Verify: `git show HEAD~1:CLAUDE.md | sha256sum` matches `sha256sum /home/developer/workspace/homelab/AGENTS.md` after the commit lands.

4. **AC4 — Git commit lands on the working branch.** Exactly one commit is added to `decommission/context-stack-phase-1` with message `schema: Pass 1 — CLAUDE.md → @AGENTS.md stub redirect (Astral pattern, ADR-003)`. Verify: `git log -1 --pretty=%s` returns that exact subject.

5. **AC5 — Diff is exactly two files.** The commit modifies/adds exactly `CLAUDE.md` and `AGENTS.md` and touches no other files. Verify: `git show --stat HEAD` lists exactly two paths and zero others.

6. **AC6 — Claude Code resolves the import.** A new Claude Code session opened with `cwd=/home/developer/workspace/homelab` reads the rules from `AGENTS.md` via the `@AGENTS.md` import. Verify: see Verification Probe 1 below.

7. **AC7 — Existing gitnexus hooks still fire.** The `~/.claude/hooks/gitnexus/pre.sh` and `~/.claude/hooks/gitnexus/post.sh` hooks continue to execute on tool calls in the new session (the rename does not break the hook chain — they are settings-driven, not file-driven). Verify: tail `~/.claude/hooks/gitnexus/*.log` (or equivalent hook output) and confirm a new entry appears after running any tool call in the new session.

8. **AC8 — Reversibility via single revert.** `git revert <commit-sha>` (no flags, no manual edits) restores the pre-story state: `CLAUDE.md` is back at 6515 bytes with original content, `AGENTS.md` no longer exists. Verify: in a scratch worktree, run the revert and confirm with `sha256sum CLAUDE.md` matching the pre-story hash and `ls AGENTS.md` exiting non-zero.

9. **AC9 — No other files created.** No `.claude/rules/`, no path-scoped `AGENTS.md` under subdirectories, no settings.json edits. Verify: `git diff HEAD~1 HEAD --name-only` returns exactly two lines.

10. **AC10 — Frontmatter remains absent.** Per Anthropic memory docs, agent-instruction files do not require YAML frontmatter; AGENTS.md must NOT have any added during the rename. Verify: `head -1 /home/developer/workspace/homelab/AGENTS.md` is `# Claude Code Configuration - RuFlo V3` (the original H1), not `---`.

## Implementation Steps

Execute from `/home/developer/workspace/homelab` on branch `decommission/context-stack-phase-1` (already current per pre-flight).

```bash
# Pre-flight: capture pre-state hash for AC3/AC8 verification
sha256sum /home/developer/workspace/homelab/CLAUDE.md > /tmp/E1.S1-pre.sha256
cat /tmp/E1.S1-pre.sha256

# Step 1: Rename CLAUDE.md to AGENTS.md
mv /home/developer/workspace/homelab/CLAUDE.md /home/developer/workspace/homelab/AGENTS.md

# Step 2: Create stub CLAUDE.md with ONLY the import directive
printf '@AGENTS.md\n' > /home/developer/workspace/homelab/CLAUDE.md

# Step 3: Stage and commit (named files only — never `git add -A`)
git -C /home/developer/workspace/homelab add CLAUDE.md AGENTS.md
git -C /home/developer/workspace/homelab commit -m "schema: Pass 1 — CLAUDE.md → @AGENTS.md stub redirect (Astral pattern, ADR-003)"

# Step 4: Verify post-commit invariants
git -C /home/developer/workspace/homelab show --stat HEAD
wc -c /home/developer/workspace/homelab/CLAUDE.md  # expect 11
sha256sum /home/developer/workspace/homelab/AGENTS.md  # expect to match /tmp/E1.S1-pre.sha256 (different filename, same hash)
```

Then open a new Claude Code session with cwd `/home/developer/workspace/homelab` and run Verification Probes 1-3.

## Verification Probes

Run each in a freshly opened Claude Code session (not the one that performed the commit) at `cwd=/home/developer/workspace/homelab`.

**Probe 1 — File-organization rule still applies (proves AGENTS.md content was loaded).**
Ask Claude: *"Create a placeholder test file for a hypothetical login flow."*
Expected behavior: Claude places the file under `/tests/` (per the "File Organization" rule in AGENTS.md), NOT in the repo root. If Claude proposes writing to root, AC6 fails — the import did not resolve.

**Probe 2 — Concurrency rule still applies (second-order proof of full file load).**
Ask Claude: *"Read three files: package.json, README.md, and CLAUDE.md."*
Expected behavior: Claude batches all three reads in a single message (per the "1 MESSAGE = ALL RELATED OPERATIONS" rule). If Claude issues three sequential read messages, the rule was not loaded.

**Probe 3 — Hooks fire on tool use.**
After running Probe 1 or 2, inspect hook output (e.g., `ls -lt ~/.claude/hooks/gitnexus/*.log 2>/dev/null` or whatever logging path the hooks use; if the hooks write to OMEGA/Graphiti, query the most recent episode). Confirm a hook entry exists with a timestamp after the new session opened.

If all three probes pass, Pass 1 is verified. If any probe fails, execute the Rollback below and re-open story.
