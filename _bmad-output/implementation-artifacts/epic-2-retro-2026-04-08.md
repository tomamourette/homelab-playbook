## Challenges and Growth Areas

### Pattern 1: Architecture Gaps Resolved Per-Story

All 4 stories required architecture discovery (OMEGA version, hook format, entity_scoping behavior, Hermes MCP command). The architecture doc was written before hands-on investigation and is now stale.

**Root cause:** Third-party tool integration requires hands-on discovery. Architecture was necessarily speculative for OMEGA specifics.

**Impact:** No story failures — discovery-first pattern handled it. But the architecture doc no longer reflects reality.

### Pattern 2: dev-host Meta Dependency Friction

Every `include_role` invocation pulls in the full `dev-host` dependency chain, requiring dummy variables (`git_user_name`, `git_user_email`, etc.) to be passed. This is friction on every deploy.

**Root cause:** `meta/main.yml` declares `dev-host` as a hard dependency. When using `include_role tasks_from:`, Ansible still processes meta dependencies.

**Impact:** Minor friction. Workaround is passing the required vars. Not a blocker but adds noise to deploy playbooks.

### Pattern 3: A/B Fix Comparison Insufficient Data

3 A/B comparisons across Epics 2.2-2.3, all ties (score 50 vs 50). All findings were single-line Ansible YAML fixes where inline and autoresearch:fix produce identical results.

**Root cause:** Ansible YAML fixes are syntactically simple. The A/B mechanism's value is in complex multi-file fixes where approaches may diverge.

**Impact:** None — mechanism works correctly, just needs more diverse data.

## Key Insights and Learnings

1. **Discovery-first pattern is the right approach for third-party integration.** Don't fight the architecture gaps — design stories with Task 0/Task 1 for investigation, then implement based on actual behavior.

2. **Upstream commands beat custom tooling.** `omega hooks setup`, `omega backup`, `omega consolidate` — using the tool's own commands instead of reimplementing their logic in Ansible reduces maintenance and improves correctness.

3. **OMEGA's project scoping works through `PROJECT_DIR` env var, not config.** The `entity_scoping` config flag is a Pro-tier placeholder. Actual isolation is via `project` metadata on memories and `project_path` SQL filtering in queries.

4. **Dedup only works through `auto_capture()`, not CLI `store`.** The production hook path (`auto_capture`) has built-in similarity detection. Direct `omega store` is a raw insert. This is by design.

5. **systemd timer with `Persistent=true` is the right backup strategy.** Catches up on missed runs after reboot. Combined with `omega backup` keeping last 5, this provides <=24h RPO without cron.

6. **blockinfile with Ansible markers is ideal for cross-role writes.** Used in `configure-gitignore.yml` and `wire-hermes.yml`. Idempotent, clearly marked, and doesn't clobber existing content.
