The 63s outlier on 162-0 (08:37:07Z) corresponds to last_sync=08:36:04Z,
i.e. one cycle before the AC-4 cycle ran — the next 1-min cycle was about
to fire when the sampler caught the window. The sampler runs at 10s cadence
while pvesr runs at 60s cadence, so any sample taken 0-10s before a fresh
snapshot lands will show age = (cycle_period + 0..10s) ≈ 60-70s.
This is an aliasing artefact, NOT an RPO breach: the actual RPO ceiling
is bounded by the cycle period + cycle duration ≈ 60s + 3s = 63s.
